# IPAS AI 初中級備考知識地圖 🎓🌱 (AI 增強版)
> **以「AI 從小孩到成人的成長歷程」為主視覺心智模型，雙軌對應經濟部 iPAS「AI 應用規劃師」初級與「人工智慧應用工程師」中級檢定考科。**

---

## 🌟 核心設計哲學：心智模型與考綱雙軌整合

學習 AI 往往容易迷失在深奧的數學公式、名詞縮寫（CNN, RNN, SGD, AUC...）與法規中。  
本系統將整個 AI 發展與技術體系，視為一個**人類小孩從小到大的心智成長過程**，劃分為三大階梯：

```
 🌱 童年啟蒙期 (0~12歲)      ➔      🌿 青年專精期 (13~22歲)      ➔      🌳 成人實戰期 (23歲以上)
【感官與認知・打好地基】           【大腦突觸發育・演算法深造】          【職場落地・工程評估與社會責任】
   • 1-1 AI 歷史與學派 (符號/連結)     • 2-1 經典 ML (線性/邏輯/樹/SVM)      • 3-1 評估指標 (混淆矩陣/ROC-AUC)
   • 1-2 資料前處理 (GIGO/清洗)        • 2-2 深度神經網路與反向傳播           • 3-2 大模型進階 (RAG/微調/Agent)
   • 1-3 學習三大範式 (監督/非監督/強化) • 2-3 電腦視覺 (CNN 卷積與池化)       • 3-3 工程部署與 MLOps (量化/ONNX)
   • 1-4 LLM 與 Prompt 提示工程        • 2-4 語言與專注力 (RNN/Transformer)   • 3-4 AI 倫理法規 (EU AI Act/XAI)
                                      • 2-5 防止死背 (Overfitting/Dropout)
```

## 🚀 雙引擎核心功能亮點 (方案 3 升級完成)

1. **內建高頻題庫大幅擴充（65+ 題大題庫）**：
   - 涵蓋 iPAS 官方必考情境題、混淆矩陣指標計算、卷積尺寸計算、防止過擬合技術與最新 AI 倫理法規。
   - 即使完全不連網，開箱即可隨時順序刷題或隨機抽題！
2. **✨ 內建 Gemini AI 無限智慧動態出題引擎**：
   - 每個節點皆具備「AI 出題」功能，串接 Google Gemini API (`gemini-2.5-flash`)。
   - 可自選題數（1/3/5 題）與出題風格（綜合題、實務情境題、演算法觀念題、指標計算題）。
   - **一鍵永久入庫**：生成的題目可直接點擊「存入本節點題庫」，自動同步寫入 LocalStorage。
3. **🎲 多元測驗模式**：
   - **全真循序測驗**：完整演練該節點所有收錄考題。
   - **🎲 隨機抽 3 題**：快速模擬短測驗，適合通勤零碎時間。
   - **✨ AI 即時動態測驗**：完全由 AI 生成的全新題目即時測驗。
4. **雙層知識卡精解**：
   - **第一層：生活擬人化口訣**（如：「Overfitting 就是只會死背考古題的書呆子」）。
   - **第二層：IPAS 官方硬核考點條列與公式解讀**。
5. **考前錯題筆記本**：
   - 任何模式答錯的題目（包含 AI 生成題）皆自動收錄進錯題專區，支援階段篩選、重新複習與「搞懂後移除」。
6. **本地儲存與資料備份**：
   - 答題進度、API Key、自訂題庫完全儲存於瀏覽器 `LocalStorage`，零隱私洩漏風險。
   - 支援 **一鍵 JSON 匯出備份** 與 **自訂題庫 JSON 匯入**。

## 🔑 如何設定 Gemini API Key（30 秒免費申請）

1. 前往 [Google AI Studio](https://aistudio.google.com/app/apikey) 點擊 **Create API Key**。
2. 複製取得的金鑰（開頭為 `AIzaSy...`）。
3. 在本備考網站右上角點擊 **「設定 AI Key」**，貼上並儲存即可！
4. 儲存後立即解鎖全節點「✨ AI 隨機出題」功能。
